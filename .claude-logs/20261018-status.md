- 28 content types claimed; no-plugin files get a text view or a note

## deviations from the brief (all in NOTES.md with evidence)
- swiftc + Makefile instead of xcodegen/xcodebuild (no xcode here)
- plugins live in the extension's own container, not an app group (1 to 2 s
  first-read penalty per process measured with the app group)
- extension holds com.apple.security.network.client (webkit helpers exit(1)
  without it); offline is enforced by a content rule list instead
- declining a file does not fall back to apple's preview on 15.7, so the
  host renders a built-in fallback

## gotchas for next time
- use /usr/bin/log, `log` is a zsh builtin
- `make install` must go through scripts/install.sh (re-registration)
- wkwebview caches harness pages: add a cache-busting query when testing
- `var status` in a page script collides with window.status
