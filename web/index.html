Spacebar

Quick Look previews from plugins. Press space on a file in Finder; a folder of HTML and JS renders it.

  • A plugin is a folder: plugin.json, index.html, your JS. No build step.
  • The host hands the plugin the file (text, bytes, JSON, or a native SQLite summary) and shows the result.
  • Ships with geojson (map, zero dependencies) and sqlite (tables, rows, schema).
  • Offline by design: no network, no filesystem, sandboxed.
  • Dev harness in the app and in the browser. scripts/new-plugin.sh gives you a working plugin to edit.

Install

brew tap gregsadetsky/tap && brew install --cask spacebar

Not signed with an Apple developer id yet: macOS refuses it once. System Settings → Privacy & Security → Open Anyway, or xattr -dr com.apple.quarantine ~/Applications/Spacebar.app. Then, if previews don't show: System Settings → General → Login Items & Extensions → Quick Look → Spacebar.
